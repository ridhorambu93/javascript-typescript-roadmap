# JavaScript & TypeScript Learning Roadmap

A structured, self-paced learning roadmap for mastering modern JavaScript (ES6+) and TypeScript — designed for developers with prior backend experience who want to seriously level up in the JS ecosystem.

**Background:**
- 5 years of coding experience (Laravel, Java, Python, jQuery)
- Goal: understand and confidently use modern JS and TypeScript
- Schedule: weekends, 2–3 hours per session
- Learning style: read code, build something immediately

---

## Overview

| Phase | Topic | Estimated Time |
|-------|-------|----------------|
| Phase 1 | Modern JavaScript (ES6+) | 3–4 weeks |
| Phase 2 | TypeScript Fundamentals | 2–3 weeks |
| Phase 3 | Practice & Mini Projects | 3–4 weeks |
| **Total** | | **8–11 weeks** |

> Based on 2–3 hours per session, 2 days per week (weekends).
> Pace is flexible — adjust to your own schedule.

---

## How to Use

1. Read `PROGRESS.md` at the start of each session
2. Check off completed items in the todolist
3. Write your notes in each phase's `notes.md`
4. Save all exercise files inside the `exercises/` folder
5. Don't move to the next phase until at least 80% of the current phase's todolist is done
